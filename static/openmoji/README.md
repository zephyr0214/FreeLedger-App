# OpenMoji

本目录下的 4567 个 SVG 来自 [OpenMoji](https://openmoji.org/) 的彩色图标集（`color/svg`）。

- 上游仓库：https://github.com/hfg-gmuend/openmoji
- 固定提交：`3e01de523ddefe9c5e46a7765b15efef04bf9002`（2026-11-04）
- 许可：图标为 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)，完整文本见 `LICENSE.txt`
- 用途：自由记的分类图标（用户自选、默认分类、历史图标迁移）

文件名是 OpenMoji 的十六进制码点（如 `1F35C.svg`），应用里以该码点作为分类 `icon` 字段的值。
